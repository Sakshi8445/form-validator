# 📝 Form Validator

A client-side form validation project built with HTML, CSS and JavaScript. It checks user input in real time, shows clear error messages, and redirects to a thank-you page only when all fields are valid.

## ✨ Features

- Validation for full name, email and password fields
- Error messages shown next to the field that has the problem
- Email format checking
- Password rules check
- Form is submitted only when all inputs are valid
- Redirects to a thank-you page after successful submission
- Clean and responsive layout

## 🛠 Tech Stack

- **HTML5** for structure
- **CSS3** for styling
- **JavaScript (ES6)** for validation logic and DOM manipulation

## 📁 Project Structure

```
form-validator
├── index.html        # Form page
├── style.css         # Styling
├── script.js         # Validation logic
└── thank-you.html    # Page shown after successful submit
```

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Sakshi8445/form-validator.git
```

2. Open the folder and double-click `index.html` in your browser.

No installation or build step is needed.
